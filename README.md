# 三连杆三维工作空间示意

这个示例用 Python、NumPy 和 Matplotlib 描绘一个三连杆串联机构的三维工作空间，并显示可交互姿态。左侧点云是关节角限制内、末端执行器能到达的位置集合。

## 模型约定

默认连杆长度为：

```text
L1 = 100
L2 = 20
L3 = 30
```

三个连杆在各自局部坐标系的正 z 轴方向延伸，采用右手坐标系和主动旋转。三个关节角及限制分别是：

```text
q1: 绕 base frame 的 z 轴，范围 [-180°, 180°]
q2: 绕第一级旋转后的局部 y 轴，范围 [-40°, 40°]
q3: 绕前两级旋转后的局部 x 轴，范围 [-110°, 110°]
```

因此旋转顺序是：

```text
R = Rz(q1) @ Ry(q2) @ Rx(q3)
```

各段位置为：

```text
p1 = Rz(q1) @ [0, 0, L1]
p2 = p1 + Rz(q1) @ Ry(q2) @ [0, 0, L2]
p3 = p2 + Rz(q1) @ Ry(q2) @ Rx(q3) @ [0, 0, L3]
```

这里 `p3` 是末端位置，`R` 是末端 frame 相对于 base frame 的姿态。

如果你的第二、第三个旋转轴始终固定在 base frame，而不是随前级 frame 一起运动，公式会不同；当前代码采用的是串联机构中更常见的“前级局部轴”解释。

## 连续逆解与工作空间限制

解析逆解在工作空间外或 `q1` 靠近 ±180° 时很容易跳变：`atan2` 会在负 X 轴切开，同一位置还有多组肘部解，误差稍差一点就会换解，于是关节从 180° 翻到 -180°。

这里用的方法是 **从上一拍关节角出发的阻尼最小二乘（DLS）+ 关节锁死**：

1. **连续性**：每一步都以上一拍 `q` 为初值做小步更新，不把 `q1` wrap 到 `(-180, 180]`。到硬限位就夹紧，不翻到另一侧。
2. **工作空间**：可达集合就是关节限制下正解的像。关节始终夹在限位内，末端就自动贴着工作空间走，不会给出工作空间外的构型。
3. **部分关节到限位、其余仍可动**：某个关节已经在限位，并且这一步还想往外推时，把它从雅可比里去掉（`dq_i = 0`），用剩下的自由关节再解一次 `dq_free = J_free^+ * dx`。例如 `q1` 顶在 180° 时，`q2`、`q3` 仍可沿边界跟踪高度和半径。

交互窗口右侧的 XYZ 滑块就是这条跟踪律。状态栏会标出当前哪些关节被锁死、哪些仍在动。笛卡尔目标本身不做工作空间裁剪：目标可以给到可达域以外，关节仍停在限位内，末端贴着边界走。

## MuJoCo 逆解过程可视化

`three_link_mujoco.py` 用同一套 FK/IK：红色球是**不受工作空间限制**的目标，三条连杆的关节仍受 `q1∈[-180°,180°]`、`q2∈[-40°,40°]`、`q3∈[-110°,110°]` 限制。每一帧只走一步 DLS，所以可以看到逆解逐步执行，而不是一下跳到终值。

```bash
pip install mujoco
python three_link_mujoco.py
```

或：

```bash
python three_link_workspace.py --mujoco
```

操作：

- `A/D`：目标 ±X，`W/S`：±Y，`Q/E`：±Z（目标可移出工作空间）
- `1`–`7`：脚本目标，其中 `4`–`6` 在可达域外
- `R`：回到示例姿态

无窗口回放迭代过程：

```bash
python three_link_mujoco.py --demo
```

离屏把执行过程渲成图：

```bash
python three_link_mujoco.py --record ik_demo.gif
```

## 运行

## 运行

建议使用 Python 3.10 或更高版本：

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python three_link_workspace.py
```

默认按关节分别密采样末端可达点：`q1` 步长由 `--step` 控制（默认 10°），`q2`/`q3` 自动更密，从而得到连续的可达点云而不是稀疏壳层。可以调整基础采样间隔：

```bash
python three_link_workspace.py --step 5
```

只计算并打印示例位姿、不打开绘图窗口：

```bash
python three_link_workspace.py --no-plot
```

连续逆解的回归测试（不需要打开窗口）：

```bash
python -m unittest test_three_link_workspace.py
```

打开绘图窗口后，底部左侧是 `q1`、`q2`、`q3` 关节滑块，右侧是末端目标 `X`、`Y`、`Z`。拖动关节滑块会正解到当前末端；拖动 XYZ 会从上一拍关节角做连续逆解。目标超出可达空间时，末端停在工作空间边界上（橙色），黑色叉号仍表示想去的目标。输入超出关节限制的数值会夹紧到允许范围内，不会从 -180° 翻转到 180°。

工作空间点云是固定的，程序启动时计算一次；实时拖动时只更新机构姿态和当前末端点。也可以导出一个可旋转、缩放的交互式 HTML：

```bash
python three_link_workspace.py --export-html workspace.html --no-plot
```

然后用浏览器打开 `workspace.html`。HTML 中的工作空间是当前关节限制下的固定可达点云，包含示例角度 `(30°, 25°, -40°)` 下的机构姿态。

工作空间和姿态图都支持鼠标交互：

- 在 3D 坐标区域按住鼠标左键拖动：旋转视角；
- 使用鼠标滚轮：缩放；
- X/Y/Z 三个方向的显示比例已固定为 `1:1:1`。

如果窗口完全不能拖动，通常是因为使用了非交互后端（例如 `MPLBACKEND=Agg` 或某些 IDE 的静态绘图窗口）。请在本地终端直接运行脚本，并确保安装了桌面 GUI 后端：

```bash
pip install PyQt6
MPLBACKEND=QtAgg python3 three_link_workspace.py
```
